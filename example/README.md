# Flutter TTS Engine Example

这是一个展示如何使用 Flutter TTS Engine 包的示例应用。

## 功能特点

- 基于 Azure Cognitive Services TTS
- 提供多种声音选项（7 种语言 × 男/女声）
- 实时文本转语音转换
- 简洁的用户界面

## 运行示例

1. 确保你已经安装了 Flutter SDK
2. 克隆这个仓库
3. 进入 example 目录
4. 运行以下命令：

```bash
flutter pub get
flutter run
```

## 使用说明

1. 选择想要的声音类型
2. 在文本框中输入要转换的文字
3. 点击"转换为语音"按钮
4. 等待转换完成

## 注意事项

- 在实际应用中，你可能需要添加错误处理和重试机制
